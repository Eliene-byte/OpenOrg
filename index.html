Autenticação direta no GitHub (Device Flow, sem senha aqui). Seu acesso fica só no seu navegador.

Publicar arquivo

O envio é feito com a sua conta GitHub: fork do repositório → arquivos em /files → atualização de /data/index.json → Pull Request para validação automática. Nada de token colado no site.

Arraste arquivos aqui ou clique para escolher

Ativar login com GitHub (2 min, uma única vez)

  1. Acesse github.com → Settings → Developer settings → OAuth Apps → New OAuth App
  2. Nome: OpenOrg · Homepage: https://eliene-byte.github.io/OpenOrg/ · Callback: o mesmo
  3. Marque Enable Device Flow → Register → copie o Client ID
  4. Cole o Client ID em config.js (oauthClientId) e faça push no GitHub

Sem segredo nenhum: o Device Flow não usa client secret. Veja o README.md.
